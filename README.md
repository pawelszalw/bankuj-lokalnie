# bankuj-lokalnie.pl

Bezpłatna, niekomercyjna strona z mapą banków spółdzielczych w Polsce i marżami ich kredytów hipotecznych.

**Strona:** https://bankuj-lokalnie.pl

## Zgłaszanie błędów

Widzisz błędny adres, telefon albo nieaktualną marżę? [Załóż issue](../../issues/new) i napisz, którego banku dotyczy i co jest nie tak. Na stronie przy każdym banku i każdej ofercie jest link „zgłoś błąd”, który otwiera gotowe zgłoszenie.

Banki, które chcą zaktualizować lub usunąć swoją ofertę, mogą też pisać na kontakt@bankuj-lokalnie.pl.

## Skąd są dane

- **Lista banków:** publiczny rejestr KNF
- **Położenie siedzib:** państwowa baza adresowa GUGiK
- **Warunki kredytów:** przekazane przez same banki, z datą
- **Mapa:** © OpenStreetMap, biblioteka Leaflet

Informacje mają charakter wyłącznie informacyjny i nie stanowią oferty w rozumieniu prawa. Wiążące warunki, w tym RRSO, przedstawia bank.
